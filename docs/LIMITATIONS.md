# ขอบเขตและข้อจำกัดของต้นแบบ

- แบบจำลองบางเรื่องเป็นสมการหรือค่าตัวอย่างเชิงสาธิตเพื่อให้เห็นการเปลี่ยนแปลงของตัวแปร มิได้ผ่านการตรวจสอบความเที่ยงตรงกับการทดลองจริง
- ฉาก 3D สร้างด้วย geometry แบบโปรแกรม ไม่ใช่ 3D scan หรือโมเดลอุปกรณ์ทดลองเหมือนจริงระดับสูง; ยังไม่มี interaction แบบจับ-เท-เขย่าจริงทุกแล็บ
- การกดทดลองคำนวณผลทันทีและมีภาพประกอบ แต่ไม่ได้ใช้การจำลองพลศาสตร์ของไหลหรือเคมีระดับโมเลกุล
- หน้าเรียนรู้ขั้นตอนทางวิทยาศาสตร์เป็นบทอธิบาย ยังไม่มี matching exercise สำหรับตอนที่ 1 ของใบงาน
- การวิเคราะห์ A/B เป็นการตรวจค่าควบคุมหลักอย่างง่าย; ในการทดลองจริงต้องควบคุมอีกหลายเงื่อนไข
- Teacher Mode แสดงผลจาก LocalStorage เฉพาะเครื่องที่เปิด ไม่สามารถดึงผลของนักเรียนคนอื่นโดยอัตโนมัติ
- ยังไม่มีระบบบัญชีผู้ใช้, การรวบรวม CSV หลายไฟล์ใน Dashboard, เสียง, offline service worker, 2D WebGL fallback, หรือ end-to-end browser automation
- แล็บ 4 มีเนื้อหาเรื่องการกัดกร่อน ซึ่งไม่เท่ากับการเกิดสนิมแดงในทุกสภาพกรด
- แล็บ 6 แยกมวลน้ำที่ระเหยจากอัตราการระเหย ซึ่งเป็นคนละตัวชี้วัด
